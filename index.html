01 · Deployment target

Board and capabilities

Choices are never changed silently. On Uno/Nano, Codegen preallocates used SRAM tensors before SD initialization, reduces UART buffers to 32/16 bytes, and stores any Softmax lookup table in Flash rather than on the stack. Remove Softmax from the topology explicitly to classify by logits.

Standard Uno / Nano SD wiring (fixed): CS = D10  ·  MOSI = D11  ·  MISO = D12  ·  SCK = D13  ·  GND = GND. Use a properly level-shifted, 5V-compatible SD module or 3.3V wiring. Codegen uses the board hardware SPI pins.
